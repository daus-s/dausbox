$$underline:{"content": "Constants"}$$

$$underline:{"content":"e"}$$ - Euler's number, the limit of (1 + 1/n)^n as n approaches infinity. represented as 2.718281828459045
$$underline:{"content":"pi"}$$ - the ratio of a circle's circumference to its diameter. represented as 3.141592653589793
$$underline:{"content":"phi"}$$ - the golden ratio, defined as (1 + sqrt(5)) / 2. represented as 1.618033988749895

$$underline:{"content": "Functions"}$$

$$underline:{"content": "sqrt(x)"}$$ - returns the square root of x, defined for any non-negative number.

$$underline:{"content": "fact(x)"}$$ - factorial of x, defined for any non-negative number. for non-integral inputs, each factor includes the fractional part of the input.
$$underline:{"content": "floor(x)"}$$ - floor of x, defined for any number. returns the largest integer less than or equal to x.
$$underline:{"content": "ceil(x)"}$$ - ceil of x, defined for any number. returns the smallest integer greater than or equal to x.
$$underline:{"content": "round(x)"}$$ - round of x, defined for any number. returns the nearest integer to x.
$$underline:{"content": "abs(x)"}$$ - absolute value of x, defined for any number. returns the non-negative value of x.
$$underline:{"content": "isprime(x)"}$$ - returns true if x is a prime number, false otherwise. defined for any non-negative integer. checks factors up to sqrt n, where n is the absolute value of x.
$$underline:{"content": "min(a, b)"}$$ - returns the smaller of a and b, defined for any two numbers.
$$underline:{"content": "max(a, b)"}$$ - returns the larger of a and b, defined for any two numbers.
$$underline:{"content": "gcf(a, b)"}$$ - greatest common factor of a and b, defined for any two numbers.
$$underline:{"content": "lcm(a, b)"}$$ - least common multiple of a and b, defined for any two numbers.
$$underline:{"content": "factor(x)"}$$ - returns the prime factorization of x, defined for any not factorization._valid:
$$underline:{"content": "sieve_of_eratosthenes(n)"}$$ - returns a list of all prime numbers less than or equal to n, defined for any non-negative integer n.
$$underline:{"content": "is_int(n)"}$$ - returns true if n is an integer, false otherwise. defined for any number.
