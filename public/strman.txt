$$underline:{"content": "mod str"}$$

the member functions of the `str` module take the string on which to operate as the first argument and auxiliary arguments as per the function's implementation. as dasl enforces immutability through scopes, the original string is not modified by the functions and a new copy is returned. this does create some performance considerations. but once again, if you are looking for performance, dauslang is not the language for you

to view only the members of the `str` module, enter command `str`.

$$underline:{"content": "split(string, delimiter)"}$$ - splits a string into parts based on a delimiter
ex:
┌──dasl──────────────────────────────────────────────┐
│ use str                                            │
│ str.split "hello,world", "," -> ["hello", "world"] │
└────────────────────────────────────────────────────┘

$$underline:{"content": "join(string[], separator)"}$$ - joins a list of strings into a single string. this solves the fencepost problem only prepending the delimiter after the first string.
ex:
┌──dasl─────────────────────────────────────────────┐
│ use str                                           │
│ str.join ["hello", "world"], " " -> "hello world" │
└───────────────────────────────────────────────────┘

$$underline:{"content": "chars(string)"}$$ - converts a string into a list of characters
ex:
┌──dasl──────────────────────────────────────────┐
│ use str                                        │
│ str.chars "hello" -> ['h', 'e', 'l', 'l', 'o'] │
└────────────────────────────────────────────────┘

$$underline:{"content": "wrap_lines(string, width)"}$$ - wraps a string into lines of a given width
ex:
┌──dasl─────────────────────────────────────────────────┐
│ use str                                               │
│ str.wrap_lines "hello world", 5 -> ["hello", "world"] │
└───────────────────────────────────────────────────────┘
ex:
┌──dasl───────────────────────────────────────────────────────────┐
│ use str                                                         │
│ str.wrap_lines "hello world", 3 -> ["he-", "llo", "wo-", "rld"] │
└─────────────────────────────────────────────────────────────────┘

$$underline:{"content": "substr(string, first, last)"}$$ - returns a substring of the given string from `first` to `last` (inclusive, exclusive). for the mathematically inclined of you: [first, last)
ex:
┌──dasl────────────────────────────┐
│ use str                          │
│ str.substr "hello", 1, 3 -> "el" │
└──────────────────────────────────┘

$$underline:{"content": "rep(string, n)"}$$ - repeats a string `n` times, mainly used to generate padding for strings or drawing with characters
ex:
┌──dasl───────────────────┐
│ use str                 │
│ str.rep ".", 3 -> "..." │
└─────────────────────────┘

$$underline:{"content": "replace(string, old, new)"}$$ - replaces all occurrences of `old` in `string` with `new`
ex:
┌──dasl────────────────────────────────────────────────────────┐
│ use str                                                      │
│ str.replace "hello world", "world", "there" -> "hello there" │
└──────────────────────────────────────────────────────────────┘

$$underline:{"content": "find(string, pattern)"}$$ - finds the first occurrence of `pattern` in `string` and returns its index, or `null` if not found
ex:
┌──dasl────────────────────────────────┐
│ use str                              │
│ str.find "hello world", "world" -> 6 │
└──────────────────────────────────────┘
ex:
┌──dasl──────────────────────────────────────┐
│ use str                                    │
│ str.find "hello world", "universe" -> null │
└────────────────────────────────────────────┘
