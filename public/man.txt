
  $$invert:{"content": " DAUSBOX "}$$

  A nostalgic terminal experience inpired by DOSBox and powered by Dauslang: my custom scripting language!

  $$invert:{"content": " Commands "}$$

  $$populate:{"display":"ls", "command":"ls"}$$ - list of projects I have created (try resizing the window to see how it handles changing screen width!)
  $$populate:{"display":"whoami", "command":"whoami"}$$ - prints a brief bio of Daus (me!), the author of this page
  $$populate:{"display":"resume", "command":"resume"}$$ - opens my resume in a new tab

  $$populate:{"display":"man", "command":"man"}$$ - prints this manual

  $$populate:{"display":"kofi", "command":"kofi"}$$ - buy me a coffee on kofi!
  $$populate:{"display":"twitch", "command":"twitch"}$$ - opens my twitch channel in a new window

  $$populate:{"display": "okigetit", "command": "okigetit"}$$ - disables the welcome message
  $$populate:{"display": "greetme", "command": "greetme"}$$ - enables the welcome message
  $$populate:{"display":"attrs", "command":"attrs"}$$ - lists the links to the resources I used from $$link:{"display": "flaticon", "link": "https://www.flaticon.com"}$$.

  $$populate:{"display": "conway", "command": "conway"}$$ - plays conways game of life with a randomized initial board

  $$invert:{"content": " Built-in Modules "}$$

  dauslang provides a set of built-in modules for common tasks including a math and string libraries. Dasl also features a time module and random number generator, though lacking documentation.

  $$populate:{"display": "math", "command": "man math"}$$ - to learn more use `man math`
  $$populate:{"display": "str", "command": "man str"}$$ - to learn more use `man str`

  To see the members of a module, enter just the name of the module and press enter. A default formatted entry will be returned displaying the name and types of the members.
  ex:
  ┌──dasl──────────────┐
  │ dausbox> time      │
  │ module:            │
  │  _name: "time"     │
  │  now: now()        │
  │  clock: clock()    │
  │  offset: 420       │
  │  Bench: Bench      │
  │::                  │
  └────────────────────┘

  $$invert:{"content": " Controls "}$$

  Any program can be halted by using the conventional Ctrl-C keyboard shortcut.
  When no program is executing Ctrl-C will default to the copy shortcut.
  Some programs also will listen for user input to exit (ex. $$populate:{"display": "Conway's Game of Life", "command": "conway"}$$).
